O Starbucks Clone é um projeto acadêmico de Front-End desenvolvido com o objetivo de replicar a interface do site da Starbucks. A finalidade é estritamente educacional, servindo como prática para a construção e organização de layouts web a partir de uma referência visual.

Principais pontos do projeto:

Objetivo: Colocar em prática conhecimentos de desenvolvimento web, aprimorando o pensamento analítico ao transformar um design visual em estrutura de código.

Tecnologias Utilizadas: Construído com as tecnologias base da web (HTML5, CSS3 e JavaScript), utilizando VS Code para o desenvolvimento e Git/GitHub para controle de versão e hospedagem.

Desafios e Aprendizados: O maior desafio foi organizar e estilizar os elementos para que ficassem o mais fiel possível à referência original. O processo ajudou a consolidar habilidades em estruturação de páginas, estilização de interfaces e resolução de problemas.

Estrutura: Segue o padrão clássico de projetos web estáticos (arquivos separados para html, css, js e imagens).
